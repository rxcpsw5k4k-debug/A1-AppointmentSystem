# Medical Appointment Management System
This is a Java assignment for health professional and appointment management.

## Project Structure
- HealthProfessional.java (Abstract parent class)
- GeneralPractitioner.java
- Nurse.java
- Dietitian.java
- Specialist.java
- Appointment.java
- AppointmentManager.java
- AssignmentOne.java (Main class to run the program)

## Functions
- Create different types of health professionals
- Add new appointments
- Search appointments by patient phone number
- Delete existing appointments
- Prevent duplicate appointments at the same time

## How to run
Open AssignmentOne.java and run it.
All output will be shown in the console.
